## Overview

Cloud storage is a service where a provider stores your data (documents, database backups, photos, etc.) and is responsible for keeping it **secure, accessible, and available**.

## Benefits over Local Storage

| Aspect | Local Storage | Cloud Storage |
|---|---|---|
| **Hardware management** | You monitor and replace failing drives | Provider handles all physical hardware |
| **Geographic redundancy** | Requires your own multi-site setup | Data easily replicated across regions (often globally) |
| **Data protection** | Single point of failure risk | If one region fails, data is accessible from another |
| **Scalability** | Fixed capacity, requires purchasing more hardware | Pay for what you use, scales dynamically |
| **Cost model** | Large upfront investment | Operational expense — not always cheaper, but more predictable |

## Use Cases

- Replacing large-scale local storage arrays
- Backing up smaller data (e.g. smartphone photo auto-upload)
- Global data availability for distributed users
