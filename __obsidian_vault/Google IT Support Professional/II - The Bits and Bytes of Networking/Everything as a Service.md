## Overview

Cloud computing has evolved beyond just hosting virtual machines. The concept of **"X as a Service" (XaaS)** describes different layers of abstraction that cloud providers offer.

## Service Models

| Model | Abbreviation | What's Abstracted | You Manage |
|---|---|---|---|
| **Infrastructure as a Service** | IaaS | Physical hardware, networking | OS, runtime, applications |
| **Platform as a Service** | PaaS | Infrastructure + server instances | Applications and data only |
| **Software as a Service** | SaaS | Everything — fully managed | Nothing (just use the software) |

### IaaS – Infrastructure as a Service

No need to build your own network or servers. A provider supplies the underlying infrastructure. This is [[What is The Cloud|cloud computing]] as described in its most basic form.

### PaaS – Platform as a Service

Provides an **execution environment** for applications. A web developer doesn't need a full server — just a platform where their app can run.

### SaaS – Software as a Service

Software is **centrally hosted, managed, and licensed** on a subscription basis. Users access it via a web browser.

**Examples:** Gmail for Business (Google), Office 365 Outlook (Microsoft)

SaaS is growing rapidly — modern browsers are capable enough to replace many traditional standalone applications (word processors, graphic design tools, HR management, etc.).
