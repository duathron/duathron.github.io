## iOS – Adding an Email Account

Additional accounts (beyond the primary [[Apple ID]]) can be added via **Settings → Apps → Mail → Mail Accounts → Add Account**.

### Automatic Setup (common providers)

Supported providers like [[iCloud]], [[Google]], [[Microsoft Exchange]], and [[Yahoo]] can be configured automatically with just an email address and password.

### Manual Setup (other providers)

Requires knowing the incoming/outgoing mail server settings (IMAP/POP3). These can be obtained from the email provider.

## Android – Adding & Removing Accounts

Additional accounts are managed via **Settings → Passwords & Accounts → Add Account**.

- Adding a **Google Account** automatically syncs email, contacts, and calendar to the device
- Removing an account also **deletes all associated data** (email, contacts, settings) from the device

### Account Types

| Type | Use Case |
|---|---|
| **Google** | Full sync: email, contacts, calendar, Play Store |
| **Exchange** | Corporate email (Microsoft Outlook environments) |
| **IMAP / POP3** | Standard personal email accounts |

## Android – Multiple User Profiles

Some Android devices support multiple separate user profiles via **Settings → System → Multiple Users**.

### Profile Types

| Type | Description |
|---|---|
| **Primary user (Owner)** | Full control over the device; can add/remove other users |
| **User** | Independent profile with own Home screen, apps, settings — for regular shared use (e.g. family member) |
| **Guest** | Temporary profile, easy to delete after use |
| **Restricted profile** *(tablets only)* | Owner controls which features and content are accessible — useful for parental controls |

### Managing Multiple Users (Owner only)

**Add a user:** Settings → System → Multiple Users → Add User → OK → enter name

**Switch user:** Swipe down from top → tap user icon → select user

**Delete a user:**
- As owner: Settings → System → Multiple Users → tap username → Delete User
- As non-owner: Settings → System → Multiple Users → More → Delete [username] from this device

> ⚠️ Deleting a user profile is permanent and cannot be undone.
