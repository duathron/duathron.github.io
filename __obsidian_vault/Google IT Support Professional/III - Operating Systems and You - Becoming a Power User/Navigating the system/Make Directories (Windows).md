## CLI: `mkdir`

```powershell
mkdir my_cool_folder
```

### Handling Spaces in Names

The shell interprets spaces as parameter separators. To include spaces in a directory name:

| Method | Example |
|---|---|
| **Quotes** | `mkdir "my cool folder"` |
| **Escape character** (backtick `` ` ``) | ``mkdir my` cool` folder`` |

### Escape Characters

The **backtick** (`` ` ``) is the escape character in [[PowerShell]]. It tells the shell to treat the next character literally. Other shells and programming languages may use different escape characters (e.g. `\` in Bash).
