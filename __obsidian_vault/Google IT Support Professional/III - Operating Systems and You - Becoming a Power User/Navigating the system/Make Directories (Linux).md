## CLI: `mkdir`

```bash
mkdir my_cool_folder
```

Same command as in [[Make Directories (Windows)|Windows]].

### Handling Spaces in Names

| Method | Example |
|---|---|
| **Quotes** | `mkdir "my cool folder"` |
| **Escape character** (backslash `\`) | `mkdir my\ cool\ folder` |

In Bash, the escape character is `\` (backslash), whereas [[PowerShell]] uses the backtick (`` ` ``).
